## 1. The category

Let Instr_cg(A,B) be the finite sets S = {E_1,…,E_k} of pairwise non-proportional, nonzero CP maps A→B with ΣE_i trace-preserving. Any instrument reduces to this form by dropping zero components and summing proportional ones. Physically, this forgets a record label that is independent of both the input and the conditional output.

Composition is T∘S = reduce{F∘E}. Reduction is a congruence, because proportional components compose to proportional components and zero composites drop out. So the category is associative and unital, F_E = −⊗id_E is a functor, and E⊗F ∝ E′⊗F′ iff E ∝ E′ and F ∝ F′. The tensor therefore never merges anything. As a side benefit, this fixes the interchange problem from the Def. 2.2 discussion without multisets or quotients, because hom-sets are small and the structure is strictly monoidal up to Hilbert-space associators.

What is lost is multiplicativity: only |T∘S| ≤ |S||T| holds. Lemma 4.1 therefore dies, and an adjoint need not restrict to Chan.

## 2. What replaces the grading: recorded mixing

Write each component as E_i = c_i·e(r_i), with r_i its ray and e(r_i) a fixed representative. Then S ↔ μ_S = Σ c_i δ_{r_i}, a finitely supported measure on rays. Hom(A,B) becomes {μ ≥ 0 : Σ c_i Tr_B J_i = I_A}, a genuine convex subset of a real vector space. The mixture pS ⊕ (1−p)S′ means "run S with probability p, else S′, and record which". Shared rays merge.

Composition is affine in each argument. So Φ⁻¹(g) = ε_B∘F_E(g) is an affine bijection, hence an isomorphism of convex sets, and it maps extreme points bijectively onto extreme points.

Channels are always extreme here, even non-extremal ones in the usual convex set of channels, since unrecorded mixing is not an operation in the category. Don't conflate this with extremality for instruments with a fixed outcome set under componentwise mixing (e.g. Pellonpää's work; check the citation). The criterion below differs.

## 3. Extreme points and their dimension

**Lemma.** μ is extreme iff the marginals v_i = Tr_B J_i (i ∈ supp μ) are linearly independent in Herm(A).

- *Dependent ⇒ not extreme.* If Σw_i v_i = 0 with w ≠ 0, then μ ± ε·w stays feasible since all c_i > 0, so μ is a midpoint.
- *Independent ⇒ extreme.* Any decomposition has support inside supp μ, and the constraint then fixes the coefficients.

So extreme instruments have k ≤ d_A² components. The top stratum, k = d_A², is an open subset of the affine fiber in Prop. 3.1, so it has dimension d_A²(d_A²d_B² − 1). That is Prop. 3.1 evaluated at n = d_A². A random-sample check confirmed that d_A²-tuples are generically TP, independent and pairwise non-proportional, for (d_A,d_B) up to (3,3).

## 4. Theorem and proof

**Claim.** For d_E ≥ 2, F_E has no right adjoint on Instr_cg. Nor does Instr_cg(−⊗E, B) have a representing object, for any B ≠ 0.

*Proof.* Φ⁻¹ is a piecewise-polynomial injection on Ext(A,R), so extreme sets of equal dimension must correspond (semialgebraic dimension; see §5):

d_A²(d_A²d_R² − 1) = d_A²d_E²(d_A²d_E²d_B² − 1) for every A ≠ 0.

Dividing by d_A² gives x·d_R² − 1 = x·d_E⁴d_B² − d_E² for all x = d_A². Equating intercepts gives d_E = 1, a contradiction. A = B = ℂ also works directly: states of R (dimension d_R²−1) must match extreme POVMs on E (dimension d_E²(d_E²−1)). So d_R² = d_E⁴ − d_E² + 1, which is never a square for d_E ≥ 2. That is the same number as in the Chan argument. ∎

## 1. "Only equal merge" is not coherent

Work with instruments as finite multisets of nonzero CP maps whose sum is trace-preserving. I checked the claims below with exact-fraction scripts.

- **Pair-merge, {E,E}∪Z ~ {2E}∪Z.** This is already a congruence, since equal components stay equal under composition and tensor. A complete invariant is, for each orbit of 2^ℤ-rescalings, the total weight in ℤ[1/2]. So the merging is dyadic:
  - {E, 2E} is not equivalent to {3E}.
  - The uniform 3-outcome dummy label {Φ/3, Φ/3, Φ/3} reduces to {2Φ/3, Φ/3}, not {Φ}.
  - It identifies dummy labels only when p is a power of 2, which defeats the purpose.
- **k-fold merge, {E×k}∪Z ~ {kE}∪Z for all k ≥ 2.** This is also a congruence, and it collapses to merging rationally proportional components. Then {E,2E} ~ {3E}, but {E,√2E} stay separate. Mixing is no longer idempotent: pS ⊕ (1−p)S ≠ S for irrational p. The hom-sets are not semialgebraic, and the convex machinery of the previous step is gone.
- **"Merge all equal at once" canonicalization** is not a congruence. Take S = {E,E,E′} and S′ = {2E,E′}. These have the same canonical form. Compose with T = {F,F′} where F′∘E = F∘E′ = X, F∘E = P and F′∘E′ = Q. Then T∘S canonicalizes to {2P, 3X, Q}, but T∘S′ to {2P, 2X, X, Q}.

So the principled choices are only "records are real data" (no merging beyond relabeling and dropping zero outcomes) and "forget labels independent of everything" (the proportional quotient already done).

## 2. Zero-drop-only (Instr_0): no right adjoint, complete proof

In Instr_0, morphisms are multisets of nonzero CP maps, and composition keeps only nonzero composites. This is a category, F_E is a functor, and no two components ever merge.

**Claim.** For d_E ≥ 2, Hom(−⊗E, E) is not representable in Instr_0.

*Proof.* Suppose (R, ε = {ε_j}_{j≤m}) is universal for B = E.

2. Each ρ_i has a nonzero composite, because Σ_j tr ε_j(ρ_i⊗X) = tr ρ_i · tr X > 0. With no merging, f has one component, so n = 1. Hence g is a single state ρ, exactly one outcome j is active, and ε_{j′}(ρ⊗·) = 0 for j′ ≠ j.

4. Steps 1–2 give Chan(E,B) = ⋃_j T_j(S_j). Uniqueness of g makes each T_j injective and the images pairwise disjoint, and each image is compact. Chan(E,B) is convex, hence connected, so exactly one j₀ has S_{j₀} ≠ ∅. Then T_{j₀}: State(V) → Chan(E,B) is an affine bijection.
5. Comparing dimensions gives d_V² − 1 = d_E²(d_B² − 1). For B = E, d_V² = d_E⁴ − d_E² + 1, which is never a square. ∎

This uses no grading lemma and no strata dimensions, only Prop. 3.1 at n = 1. It is pointwise in B. It also shows why deterministic targets are the obstruction: they force single-outcome sources. It breaks exactly where merging enters, because merging lets many composites collapse into one channel (step 2).

## 3. Dyadic and rational variants: partial

For any congruence ≈ between zero-drop and proportional merging, an adjoint would have to satisfy the following. These are proof sketches.

1. **Surjectivity transfers.** The quotient functor to Instr_cg makes h ↦ p(ε_B)∘F(h) a surjective, recorded-mixing-affine map Hom_cg(A,R) → Hom_cg(A⊗E,B). Surjective affine maps hit each extreme point from an extreme point, using a minimal-support argument. So the extreme-set dimensions satisfy d_A²d_E²(d_A²d_E²d_B² − 1) ≤ d_A²(d_A²d_R² − 1) for all A. This gives d_R² ≥ d_E⁴d_B².
2. **Generic injectivity.** On an open dense set of instruments the composites have no coincidences. In the dyadic case there are finitely many algebraic coincidence conditions. There Φ⁻¹ multiplies the component count by m, the number of components of ε, and is injective polynomial. So n·d_R² − 1 ≤ nm·d_E²d_B² − d_E² for all n, and together with (1) this forces m ≥ d_E² + 1.

So any hypothetical adjoint has d_R(B) ≥ d_E²d_B, which is larger than the CPM candidate E*⊗B. Its counit has more than d_E² outcomes. Its deterministic channels come from multi-component sources whose composites merge arithmetically.

I could not close this. Two things block the proof:

- Under rational mixing, extreme points are those with ℚ-independent marginals, and there is no Carathéodory bound. For example, 1 = (½ + √2/4) + (½ − √2/4) has ℚ-independent summands while d_A² = 1. Extreme sets then have unbounded dimension.
- In the surviving analogue of step 3, channels come from states in sections W_q = {σ : ε_j(σ⊗·) = q_j ε̄(σ⊗·)}. These are linear slices of State(R) of arbitrary shape, so the conclusion "Chan(E,B) ≅ State(V)" is lost.

I expect no adjoint here either, but I have no proof. Since these congruences are not physically principled, I would not spend more on them unless a referee asks.

## 2. A cleaner closure: the overlap identity

In every variant, the record-forgetting functor makes T(ρ) = ε̄(ρ⊗·) map State(R) onto Chan(E,B).

**Lemma 2.** Let ψ, ψ′ be pure states with T(ψ) = f and T(ψ′) = f′. Take minimal Kraus families {K_i}_{i≤r} for f and {K′_l}_{l≤r′} for f′. Then ⟨ψ|ψ′⟩·1_E = Σ_{il} Γ_{il} K_i†K′_l, where Γ_{il} = ⟨e_i|e′_l⟩ for orthonormal families {e_i}, {e′_l} in the Stinespring environment. In particular, ⟨ψ|ψ′⟩ ≠ 0 implies 1 ∈ span{K_i†K′_l}.

*Proof.*
1. Let W: R⊗E → B⊗G be the Stinespring isometry of ε̄, and put W_ψ = W(ψ⊗·).
2. Any Kraus family of f is related to the minimal family by an isometry u. So W_ψ x = Σ_i K_i x ⊗ e_i with e_i = Σ_a u_{ai} g_a. Then ⟨e_i|e_{i′}⟩ = (u†u)_{ii′} = δ_{ii′}, so the e_i are orthonormal.
3. W is an isometry, so W_ψ†W_{ψ′} = ⟨ψ|ψ′⟩·1.
4. Expanding W_ψ†W_{ψ′} in the Kraus families gives the identity. ∎

**Theorem 3 (pointwise, all variants).** Let d_E, d_B ≥ 2. Then Hom(−⊗E, B) is not representable in Chan, graded Instr, Instr_0, the dyadic quotient, the rational quotient or Instr_cg.

*Proof.* Split the basis of E into r = ⌈d_E/d_B⌉ consecutive blocks of size at most d_B, with the first block of size at least 2. This is always possible, since ⌈d_E/d_B⌉ ≤ d_E − 1 for d_B, d_E ≥ 2. Choose isometries V_i from block i into B with non-orthogonal ranges, and set K_i = V_iP_i. Rotate one basis vector of block 1 by a phase: V₁^θ = V₁D_θ with D_θ = diag(e^{iθ},1,…,1). Call the resulting channel f_θ.

1. **Trace-preserving and extremal.** ΣK_i†K_i = ΣP_i = 1. The products K_i†K_j occupy distinct block positions and are nonzero, so they are linearly independent. By Choi's criterion f_θ is extreme in Chan(E,B).
2. **Pure programs.** T is onto and f_θ is extreme, so the fibre T⁻¹(f_θ) is a nonempty face of State(R). It therefore contains a pure state ψ_θ.
3. **The span condition.** For θ ≠ θ′ we need 1 ∉ span{K_i†K′_l}. Since the operators occupy independent block positions, 1 lies in the span iff each diagonal block of V_i†V′_i is a nonzero scalar times the identity. For block 1 this block equals D_{θ′−θ}, which is scalar only if θ = θ′.
4. **Orthogonality.** By Lemma 2, ψ_θ ⊥ ψ_{θ′} for θ ≠ θ′. This gives infinitely many orthonormal vectors in the finite-dimensional space R, a contradiction. ∎

For the case r = 1 (d_B ≥ d_E, isometric channels), this is exactly the Nielsen–Chuang argument. For r ≥ 2 it extends that argument to extremal channels of higher Kraus rank, replacing "U†U′ ∝ I" by the span condition.

I verified the construction numerically for nine (d_E, d_B) pairs, including (3,2), (4,2) and (8,3): trace preservation, extremality, 1 in the span for θ = θ′, and 1 not in the span for θ ≠ θ′. The first three of these have d_B < d_E, the case the unitary argument could not reach.

## 4. Why cg differs

In cg, merging splits components by real weights, and the real kernel is positive-dimensional (dimension up to 4 in the checks above). So a_i can be a non-scalar vector, and rigidity fails. That is why cg needed the count or the record-forgetting route.

The pattern is arithmetic: the allowed splitting weights are integers in Instr_0, dyadic in D, rational in Q, and real in cg. Rigidity holds exactly when the weights are countable.

## 1. Infinite-dimensional separable case

**Theorem 5.** Let E, B be separable with dim E, dim B ≥ 2 (finite or infinite), with normal maps and arbitrary outcome spaces. Then Hom(−⊗E, B) is not representable by a separable R, in every variant.

The proof is Theorem 3 with four infinite-dimensional checks:

1. **Surjection T.** T(ρ) = ε̄(ρ⊗·) maps State(R) onto Chan(E,B). This is the record-forgetting argument from before.
2. **The family.** Split the basis of E into countably many blocks of size ≤ dim B. The first block has size ≥ 2, and the ranges of the isometries V_i (K_i = V_iP_i) pairwise overlap. For example, all V_i can map one basis vector of block i to a common vector u. If B is infinite-dimensional, one block with an isometry E → B suffices. Rotate one vector in block 1 by a phase, giving f_θ.
3. **Extremality.** By Arveson's criterion, a normal channel with minimal Stinespring dilation (π = id⊗1, V) is extreme iff T ↦ V†(1⊗T)V is injective on B(G). Here the products K_i†K_j sit in distinct block positions and are nonzero, so injectivity holds. The dilation is minimal because Σc_iK_i = 0 forces c_i = 0, the K_i having orthogonal supports. (Arveson 1969, Thm 1.4.6; check the numbering.) Extremality under countable mixtures follows from binary extremality, since the remainder is again a normal channel.
4. **Overlap.** Any Stinespring isometry for f_θ is (1⊗J)V with J an isometry, so Lemma 2 holds with a contraction matrix Γ. Comparing block (1,1) gives ⟨ψ_θ|ψ_{θ′}⟩ = Γ₁₁e^{iφ} = Γ₁₁, so ⟨ψ_θ|ψ_{θ′}⟩ = 0 for φ ≠ 0. This gives uncountably many orthonormal vectors in a separable R, a contradiction. ∎

**B = ℂ.** Theorem 4 needs only a finite number m of counit components. The genericity step needs only that the effects have classes in B_sa(E)/ℝ1 that are ℚ-linearly independent. It works for infinite-dimensional E, because small perturbations N_l = 1/k + δ_l keep the effects positive. ## 1. The mechanism

For finitely or countably supported instruments, recorded mixing is pS ⊕ (1−p)S′: a union of scaled copies, with proportional components merged. Under an adjunction, Ψ(g) = ε∘F(g) is a bijection Hom_cg(ℂ,R) → Hom_cg(E,B) that commutes with recorded mixing. This holds because composition distributes over the union and merging commutes with composition. So Ψ is an isomorphism of mixing structures, and it preserves extreme points and convex decompositions.

**Source side.** An ensemble in Hom_cg(ℂ,R) is a set of pairwise non-proportional PSD operators ρ_i with Σtr ρ_i = 1. Equivalently it is a finitely (or countably) supported probability measure on the *set* State(R), with weights tr ρ_i. So Hom_cg(ℂ,R) is a simplex:
- its extreme points are the single-state instruments, and
- every element is a convex combination of them in a unique way.

All its faces are simplices.

**Target side.** The minimal face of an instrument with support T is the polytope P_T = {c ≥ 0 : Σc_l v_l = 1}, where v_l = f_l†(1_B). It has dimension |T| − rank{v_l}, and its vertices are the extreme instruments, which are those with independent marginals.

## 2. A quadrilateral face in Hom_cg(E,B)

Let dim E ≥ 2 and pick a bounded Hermitian a on E that is not a scalar. Set v_l = ¼·1 + δβ_l a with β = (1, −2... ) — precisely β = (1, −1, 2, −2) and small δ, so every v_l is positive. Let f_l(X) = tr(v_l X)σ_l with distinct states σ_l on B. For B = ℂ, f_l is just the effect v_l. The f_l are pairwise non-proportional.

Here P_T = {c ≥ 0 : Σc_l = 4, Σβ_l c_l = 0} is a polygon with exactly four vertices, one for each pair of opposite-sign β. They are the extreme instruments:
- e₁₂ = {2f₁, 2f₂}
- e₃₄ = {2f₃, 2f₄}
- e₁₄ = {(8/3)f₁, (4/3)f₄}
- e₂₃ = {(8/3)f₂, (4/3)f₃}

The instrument f = {f₁, f₂, f₃, f₄} has two different decompositions into extremes:

½e₁₂ ⊕ ½e₃₄ = ¼e₃₄ ⊕ ⅜e₁₄ ⊕ ⅜e₂₃.

I verified in exact arithmetic that all four e's are trace-preserving with independent marginals, that P_T has four vertices spanning a plane (a simplex of dimension 2 would have three), and that both decompositions give the same f with all weights equal to 1.

For countable outcomes, Instr_D means countable multisets of nonzero normal CP maps modulo the *finitary* congruence generated by pair-merge and split. Two consequences:

## 2. Two lemmas

**Lemma A (finite support).** Suppose f is a finite class and g = {ρ_i} satisfies ε∘F(g) ≈ f. Then the composite multiset is finite, so every ρ_i, and every pure component of ρ̂_i, has finite support J = {j : ε_j(ψ) ≠ 0}.

**Lemma B (finite-dimensional faces).** For finite J, let V_J = ∩_{j∉J} Z_j with Z_j = {v : ε_j(|v⟩⟨v|) = 0}. Then Λ maps Herm₁(V_J) injectively into ∏_{j∈J} B_sa(E) (for B = ℂ). Hence (dim V_J)² ≤ |J|·d_E². For B = ℂ the sharper bound is (|J|−1)d_E² + 1, because Σ_j Λ_j(h) = (tr h)·1.

**Result.** For d_E ≥ 2 and d_B ≥ 2, Chan(E,B) is not affinely isomorphic to the state space of any quantum system. No Diophantine condition enters.

## Proof

1. **State spaces.** The extreme points of State(ℂ^R) are the pure states, a manifold ℂP^{R−1} of dimension 2(R−1). The total dimension is R²−1. An affine isomorphism maps extreme points bijectively and is semialgebraic, so the extreme sets must have equal dimension.

2. **Extreme channels.** By Choi's criterion, a channel is extremal iff its Kraus operators satisfy {K_i†K_j} linearly independent, so the Kraus rank is r ≤ d_E. Put N = d_Ed_B and stratify channels by Choi rank r.
   - Rank-r PSD matrices on ℂ^N form a manifold of dimension 2Nr − r².
   - The constraint Tr_B J = I is a submersion at every channel. A cokernel vector would be a Hermitian H whose action H⊗I vanishes on range J, i.e. K_iH^T = 0 for all i. That is impossible, because ΣK_i†K_i = I leaves no common kernel.
   - So stratum r has dimension 2Nr − r² − d_E². For d_E = d_B = d and r = 1 this gives d²−1, the dimension of the unitary channels.
   - Extremality is an open condition. It is realized at r = d_E by K_i = |v_i⟩⟨e_i| with unit vectors v_i ∈ ℂ^{d_B} that are pairwise non-orthogonal, which is possible once d_B ≥ 2. Such a channel is trace-preserving, and K_i†K_j = ⟨v_i|v_j⟩ |e_i⟩⟨e_j| are independent.
   - The stratum dimension increases with r (for r < N), and extremal channels have r ≤ d_E. So dim Ext Chan(E,B) = 2d_E²(d_B − 1).

3. **Comparison.** An isomorphism would need both 2d_E²(d_B−1) = 2(R−1) and R²−1 = d_E²(d_B²−1). Substituting R = d_E²(d_B−1)+1 into the second gives d_E²(d_B−1) + 2 = d_B + 1, so d_E = 1. ∎

does the same argument give a cleaner Instr_cg proof, since it identifies Chan(E,B) inside the extreme set?:

**Short answer.** The Kraus-rank argument does not transfer to Instr_cg, but the idea behind your hint does, and it gives a much cleaner proof. That proof also closes the dyadic/rational gap for the nonexistence of an adjoint.

## 1. Why the Kraus-rank argument doesn't transfer

In Instr_cg, the extreme set of Hom(ℂ,R) is State(R), and its bijection onto Ext(E,B) is not affine for ordinary (unrecorded) mixing. Channels are only the k = 1 stratum of Ext(E,B), where every channel is extreme under recorded mixing.

Under an adjunction, the channels' preimages form a foliated set. Writing ε_j for the components of the counit ε_B, ε̄ = Σ_jε_j for its coarse-grained channel, and T(ρ) = ε̄(ρ⊗·): the preimage set is a union of convex leaves W_p = {ρ : ε_j(ρ⊗·) = p_j·T(ρ) for all j}, one for each outcome-probability vector p. The Instr_0 connectedness step has no analogue here. The Kraus-rank count gives only R ≥ d_E²(d_B−1)+1, which the top-stratum count already implies.

## 2. The cg count is already escape-free

Take A = ℂ and any B. The Instr_cg count gives d_R² = (d_E²d_B)² − (d_E²−1). This lies strictly between (d_E²d_B − 1)² and (d_E²d_B)², so it is never a square for d_E ≥ 2. I checked this for d_E, d_B < 400 (no squares), and the sandwich inequality holds throughout the ranges tested.

Unlike Chan, there is no Diophantine escape for any B, because the extreme set is indexed by the Carathéodory number d_E². This is a one-equation proof, but it still needs the strata and semialgebraic-dimension machinery.

## 3. A cleaner route: forget the record

The map c({E_i}) = ΣE_i is a functor c: Instr_≈ → Chan.
- It is multiplicative: c(T∘S) = c(T)∘c(S).
- It is invariant under merging and under dropping zero outcomes. So it exists on the graded model, Instr_0, the dyadic and rational quotients, and Instr_cg.
- It is the identity on Chan and commutes with F_E.

**Lemma.** If F_E ⊣ R in any of these categories, then ε̄ := c(ε_B) is a channel R(B)⊗E → B, and T(ρ) = ε̄(ρ⊗·) maps State(R(B)) onto Chan(E,B).

*Proof.* A channel f is itself a 1-outcome instrument, so f = ε_B∘F(g) for some g ∈ Hom(ℂ,R). Applying c gives f = ε̄∘(c(g)⊗id), and c(g) = Σρ_i is a state. ∎

So an adjoint would give a deterministic, exact, universal programmable processor for all channels E→B, with program register R(B).

**Theorem.** For d_E ≥ 2, Hom(−⊗E, E) is not representable in any of these categories, so F_E has no right adjoint.

*Proof.*
1. The unitary channel Ad_U is extreme in Chan(E,E), since it has Kraus rank 1.
2. The fibre T⁻¹(Ad_U) is a nonempty face of State(R), so it contains a pure state ψ_U.
3. Let W: R⊗E → E⊗G be a Stinespring isometry for ε̄. Since the output is pure for every input, W(ψ_U⊗x) = Ux⊗η_U with η_U independent of x.
4. Taking inner products gives ⟨ψ_U|ψ_{U′}⟩·I = ⟨η_U|η_{U′}⟩·U†U′. If U†U′ ∉ ℂI, both sides vanish, so ψ_U ⊥ ψ_{U′}.
5. The unitaries diag(e^{iθ},1,…,1) are pairwise non-phase-equivalent. They give infinitely many orthogonal vectors in ℂ^R, a contradiction. ∎

Step 4 is the Nielsen–Chuang no-programming theorem (PRL 79, 321, 1997). I sanity-checked the algebra numerically (for a random pair of unitaries, I and U†U′ are linearly independent). The same argument works for any B with d_B ≥ d_E ≥ 2, using isometric channels.

## 4. What this settles and what it doesn't

- **Settled:** the dyadic and rational variants, and every intermediate congruence. The only thing used is that the quotient to Chan exists, so nothing depends on how merging is defined.
- **Not settled:** pointwise non-representability at each B with d_B < d_E in the dyadic/rational variants. There are no isometries there. The generalized overlap identity ⟨ψ|ψ′⟩I = Σ Γ_{il}K_i†K′_l (Γ a contraction) would force orthogonality whenever I ∉ span{K_i†K′_l}. That is plausible for Kraus rank below d_E, but I haven't checked it. The adjoint question needs only one B, so it is closed.
- **Not captured:** the Instr-specific witness at B = ℂ. There c lands on Chan(E,ℂ), a single point, so no contradiction arises. That case still needs the POVM-versus-ensemble count.

## 1. What breaks

- **Counit determinism (Lemma 4.1).** The prime argument uses cardinal arithmetic, and ℵ₀·ℵ₀ = ℵ₀. For atomless standard Borel spaces, Ω×Ω ≅ Ω, so "number of outcomes" isn't even defined.

## 2. What carries over

Instruments are σ-additive normal-CP-valued measures I: Σ → CP (Davies–Lewis, Ozawa). Composition runs over the product σ-algebra, with (J∘I)(X×Y) = J(Y)∘I(X). The record-forgetting map c(I) = I(Ω) is then a functor c: Instr → Chan:
- It is multiplicative: c(J∘I) = J(Ω₂)∘I(Ω₁).
- It is the identity on one-point instruments.
- It commutes with F_E.
- It is invariant under isomorphism of outcome spaces and under any coarse-graining.

So the Lemma from the last step goes through verbatim. If F_E ⊣ R, then ε̄ = c(ε_B) is a normal channel R(B)⊗E → B. The map T(ρ) = ε̄(ρ⊗·) sends normal states of R(B) onto Chan(E,B), because a channel f = ε∘F(g) gives f = ε̄∘(c(g)⊗id), and c(g) is a normal state.

## 3. Theorem and the infinite-dimensional checks

**Theorem.** Let the objects be separable Hilbert spaces, with normal maps and arbitrary standard Borel outcome spaces. Also allowed: finite-dimensional objects with arbitrary outcome spaces. If dim E ≥ 2, then Hom(−⊗E, E) is not representable, so F_E has no right adjoint.

The proof is the same as before, with these points checked in infinite dimensions:

1. **Pure programs.**
   - Decompose a program spectrally as ρ = Σλ_kψ_k and use T(ρ) = Σλ_kT(ψ_k).
   - Ad_U is extreme under countable mixtures. A CP map dominated by a Kraus-rank-one map is a scalar multiple of it (Arveson's Radon–Nikodym theorem). Trace preservation then forces equality.
   - So each pure component ψ_k implements Ad_U exactly.
2. **Overlap identity.** Normal channels have Stinespring dilations with separable environment. Steps 3–4 then give ⟨ψ_U|ψ_{U′}⟩·I = ⟨η_U|η_{U′}⟩·U†U′, hence orthogonality for non-phase-equivalent unitaries.
3. **Cardinality.** The unitaries diag(e^{iθ},1,…,1), θ ∈ [0,2π), are pairwise non-phase-equivalent. They give uncountably many mutually orthogonal vectors, which a separable R cannot hold. For finite-dimensional objects, orthogonal families are bounded by dim R, so the same argument applies there.

The argument shows more: R(B) would need Hilbert dimension at least 2^ℵ₀.

## 4. Why separability is essential

Take R = ℓ²(Chan(E,B)), with Kraus operators ⟨f|⊗K^f_i. Then ε̄(ρ⊗X) = Σ_f ⟨f|ρ|f⟩ f(X) is a normal CPTP map, and T(|f⟩⟨f|) = f. So a deterministic, exact, universal programmable processor exists once the program register is non-separable. I verified the finite analogue: for n random qubit channels, the n-dimensional lookup-table processor is trace-preserving, reproduces every channel from its basis-state program, and turns a superposition program into the classical mixture.

Since T is not injective, this doesn't give an adjoint. It does show that the no-programming route alone cannot exclude one when non-separable (or non-normal, singular-state) objects are allowed. I make no claim for that setting.

Higher-order completions made precise — §7.2(4):

**Result.** There is a minimal completion, which I'll call 𝒯 (typed quantum systems), in which −⊗E has a right adjoint for every first-order E. The internal hom is an explicit affine slice of a state space. The paper's theorem then reads "[E,B] is not a first-order object", and the intercept in Prop. 3.1 is the codimension of that slice. I verified the Choi correspondence, the counit and the codimension numerically (details in §2 and §4).

## 1. The completion 𝒯

**Objects.** A pair (H, 𝔏), where H is a finite-dimensional Hilbert space and 𝔏 is an affine subspace of trace-one Hermitian operators containing a positive-definite one. The admissible states are 𝒮 = 𝔏 ∩ Herm⁺. First-order objects are those with 𝔏 = all trace-one operators.

**Morphisms.** CP maps f with f(𝔏_A) ⊆ 𝔏_B. Equivalently f(𝒮_A) ⊆ 𝒮_B, because the positive-definite point makes 𝒮 span 𝔏.

**Tensor.** (H_A⊗H_B, aff{a⊗b : a ∈ 𝔏_A, b ∈ 𝔏_B}), with unit (ℂ,{1}).

**Prop 1.** 𝒯 is symmetric monoidal. The first-order objects form a full, strong-monoidal copy of Chan. Here "CP and f(State) ⊆ State" means exactly CPTP, and product states span all trace-one operators on a tensor product, so first-order ⊗ first-order is first-order.

## 2. The internal hom

For first-order E and typed 𝔹, define [E,𝔹] = (E*⊗B, 𝔏), where 𝔏 consists of the operators J/d_E with J the Choi operator of a map f_J satisfying f_J(State E) ⊆ 𝔏_B. For first-order B, the admissible set is exactly the normalized Choi states of channels, {J/d_E : Tr_B J = 1_E}.

**Theorem H1.** −⊗E ⊣ [E,−] on 𝒯, naturally in 𝔸 and 𝔹.

*Proof.* Use the Choi correspondence g(a) = (1/d_E)Σ|i⟩⟨j|⊗f(a⊗|i⟩⟨j|). Both hom-sets consist of CP maps f: A⊗E → B with f(a⊗τ) ∈ 𝔏_B for all a ∈ 𝔏_A and τ ∈ State(E). ∎

The counit is ε = d_E(⟨Ω|⊗1)(·)(|Ω⟩⊗1), a Bell post-selection. It is CP and trace-preserving only on the admissible slice. I checked this numerically: it reproduces the channel and has trace 1 on admissible inputs, but trace 0.97 on a generic state. A genuinely trace-preserving counit would need the Bell measurement with its correction outcomes, which is the Bell-candidate failure from earlier.

## 3. What the paper's theorem says in 𝒯

If a first-order R represented Chan(−⊗E, B), then at A = ℂ we would get State(R) ≅ Chan(E,B) affinely. That is the admissible set of [E,𝔅]. By the Kraus-rank theorem this is impossible for d_E, d_B ≥ 2. So [E,𝔅] is not isomorphic to any first-order object: **the internal hom is a typed system, not a quantum system.** For d_B = 1, [E,ℂ] ≅ ℂ is first-order, matching the earlier B = ℂ contrast for Chan.

## 4. The intercept is a codimension

The admissible set of [E,𝔅] has dimension d_E²(d_B²−1), which is dim State(E*⊗B) minus (d_E²−1). I checked this for three (d_E, d_B) pairs.

For instruments, Instr_n(A⊗E,B) = Hom_𝒯(𝔄⊗E, 𝔅_n), where 𝔅_n = (B⊗ℂⁿ, block-diagonal states). The hom-object at grade n has dimension n·d_E²d_B² − d_E². A first-order quantum-classical system on R⊗ℂⁿ has dimension n·d_R² − 1. The intercepts −d_E² versus −1 in Prop. 3.1 are exactly the normalization constraints that cut out the typed slice, and the grading is just the choice of n.

## 5. Hierarchy and literature

Iterating gives [[E,B],C] and so on. Higher-order maps are Choi operators with nested normalization constraints (Chiribella–D'Ariano–Perinotti combs). 𝒯 is the affine-slice shadow of Kissinger–Uijlen's Caus[CPM(FHilb)], which is *-autonomous. I believe my affine-span tensor agrees with their double-orthogonal closure on the objects arising here, since it does for first-order objects and slices. ## 0. Conventions

- T(H) is the set of trace-one Hermitian operators on H. HP(A,B) is the set of Hermiticity-preserving linear maps B(H_A) → B(H_B).
- **Choi.** C(f) = Σ_{ij} |i⟩⟨j| ⊗ f(|i⟩⟨j|) ∈ B(H_{A*} ⊗ H_B), where A* is H_A with the same basis.
  - C is a linear bijection from all linear maps onto B(H_{A*} ⊗ H_B).
  - It maps HP onto Herm and CP onto Herm⁺ (Choi's theorem).
  - Tr_B C(f) = Σ |i⟩⟨j| tr f(|i⟩⟨j|).
  - For linear k, (id ⊗ k)(C(f)) = C(k∘f).
- **Evaluation.** With |Ω⟩ = Σ|ii⟩ ∈ H_{A*} ⊗ H_A, put ev_{A,B}(Y) = (⟨Ω| ⊗ 1_B) Y (|Ω⟩ ⊗ 1_B) on B(H_{A*} ⊗ H_B ⊗ H_A). This is CP.

**(E0)** ev(C(f) ⊗ Y) = f(Y) for every linear f and every Y.

*Proof.* ⟨Ω|(|i⟩⟨j| ⊗ Y)|Ω⟩ = Σ_{kl} ⟨k|i⟩⟨j|l⟩⟨k|Y|l⟩ = ⟨i|Y|j⟩. Hence ev(C(f) ⊗ Y) = Σ_{ij} ⟨i|Y|j⟩ f(|i⟩⟨j|) = f(Y). ∎

## 1. The category 𝒯

**Definition 1 (typed system).** A typed system 𝔸 = (H_A, 𝔏_A) has 𝔏_A ⊆ T(H_A) an affine subspace containing a positive-definite operator. Its admissible states are 𝒮_A = 𝔏_A ∩ Herm⁺. The first-order system 𝔄 is (H_A, T(H_A)).

**Lemma 1.** aff(𝒮_A) = 𝔏_A.

*Proof.* Let p ∈ 𝔏_A be positive-definite. Positive-definite operators are open in Herm, so some relative neighbourhood of p in 𝔏_A lies in 𝒮_A. An affine subspace containing a relatively open subset of 𝔏_A has affine hull 𝔏_A. ∎

**Definition 2 (morphisms).** Hom(𝔸,𝔹) = {f ∈ CP(A,B) : f(𝔏_A) ⊆ 𝔏_B}. Composition and identities are those of CP maps.

**Lemma 2.** For f ∈ CP(A,B), f(𝔏_A) ⊆ 𝔏_B ⇔ f(𝒮_A) ⊆ 𝒮_B.

*Proof.* (⇒) f(𝒮_A) ⊆ 𝔏_B, and f(𝒮_A) ⊆ Herm⁺ because f is CP. (⇐) f is affine, so f(𝔏_A) = f(aff 𝒮_A) = aff f(𝒮_A) ⊆ aff 𝒮_B ⊆ 𝔏_B. ∎

**Proposition 1.** 𝒯 is a category, and ι: Chan → 𝒯, A ↦ 𝔄, f ↦ f, is fully faithful.

*Proof.* Closure under composition and identities is immediate. A CP map f satisfies f(T(H_A)) ⊆ T(H_B) iff tr f(X) = tr X for all X ∈ T(H_A). Since T(H_A) spans Herm(H_A) linearly, this gives tr f = tr on Herm, and by complexification on all of B(H_A). So f is CPTP. Conversely CPTP maps preserve T. ∎

## 2. Monoidal structure

**Definition 3.** 𝔸 ⊗ 𝔹 = (H_A ⊗ H_B, 𝔏_A ⊠ 𝔏_B), where 𝔏_A ⊠ 𝔏_B = aff{a ⊗ b : a ∈ 𝔏_A, b ∈ 𝔏_B}. The unit is (ℂ, {1}).

**Proposition 2.** 𝒯 is symmetric monoidal, and ι is strong monoidal.

*Proof.*
1. *Well-defined.* Affine combinations of trace-one Hermitian operators are trace-one Hermitian, and p_A ⊗ p_B is positive-definite.
2. *Functoriality.* For f ∈ Hom(𝔸,𝔸′) and g ∈ Hom(𝔹,𝔹′), f⊗g is CP and maps a ⊗ b to f(a) ⊗ g(b), a product in 𝔏_{A′} ⊠ 𝔏_{B′}. By linearity it maps affine hulls into affine hulls.
3. *Associativity.* (𝔏_A ⊠ 𝔏_B) ⊠ 𝔏_C = aff{x ⊗ c}. Each x ∈ 𝔏_A ⊠ 𝔏_B is an affine combination of products a ⊗ b, and x ↦ x ⊗ c is affine. So the set equals aff{a ⊗ b ⊗ c}, the same set as for the other bracketing.
4. *Unit and symmetry.* Both hold similarly. The associators, unitors and braidings are unitary conjugations, which lie in 𝒯 by the above. Coherence is inherited from fdHilb.
5. *ι strong monoidal.* The inclusion ⊆ is clear. For ⊇, take X ∈ T(H_A ⊗ H_B). Products of states span Herm(H_A ⊗ H_B), so X = Σ c_k ρ_k ⊗ σ_k with real c_k and Σc_k = tr X = 1. So X is an affine combination of product states. ∎

## 3. The internal hom

Fix a first-order 𝔼 = ι(E).

**Definition 4.** For typed 𝔹, set 𝔏_{[E,𝔹]} = {C(f)/d_E : f ∈ HP(E,B), f(T(H_E)) ⊆ 𝔏_B}, and [E,𝔹] = (H_{E*} ⊗ H_B, 𝔏_{[E,𝔹]}).

**Lemma 3.** [E,𝔹] is a typed system.

*Proof.*
1. *Trace one.* f(τ) ∈ 𝔏_B has trace 1 for all τ ∈ T(H_E), so tr∘f = tr on Herm(H_E) and Tr_B C(f) = 1_E. Hence tr C(f)/d_E = 1.
2. *Affine.* Write T(H_E) = τ₀ + Herm₀ with τ₀ = 1/d_E and Herm₀ the traceless Hermitians, and 𝔏_B = b₀ + 𝔙_B. The condition is f(τ₀) ∈ b₀ + 𝔙_B and f(Herm₀) ⊆ 𝔙_B. This is an affine condition on f, and C is a linear bijection.
3. *Positive-definite point.* For positive-definite b′ ∈ 𝔏_B, the map f₀(X) = tr(X) b′ satisfies f₀(T) = {b′} ⊆ 𝔏_B, and C(f₀) = 1 ⊗ b′ is positive-definite. ∎

**Definition 5.** ε_𝔹 = d_E · ev_{E,B}: [E,𝔹] ⊗ 𝔼 → 𝔹.

**Lemma 4.** ε_𝔹 ∈ Hom([E,𝔹] ⊗ 𝔼, 𝔹).

*Proof.* ε is CP. By (E0), ε(C(f)/d_E ⊗ τ) = f(τ) ∈ 𝔏_B for f admissible and τ ∈ T(H_E). By linearity, ε maps the affine hull of these products into the affine space 𝔏_B. ∎

**Theorem 1.** For typed 𝔸, 𝔹 the map Φ_{𝔸,𝔹}: Hom(𝔸,[E,𝔹]) → Hom(𝔸⊗𝔼, 𝔹), g ↦ ε_𝔹 ∘ (g ⊗ id_E), is a bijection. It is natural in 𝔸 and 𝔹, so −⊗𝔼 ⊣ [E,−] on 𝒯, with counit ε.

*Proof.*

*(a) Φ lands in Hom.* g ⊗ id_E is a morphism by Proposition 2, and ε is a morphism by Lemma 4.

*(b) Inverse.* For f ∈ Hom(𝔸⊗𝔼, 𝔹) define Ψ(f)(X) = (1/d_E) Σ_{ij} |i⟩⟨j| ⊗ f(X ⊗ |i⟩⟨j|).
- Ψ(f) is CP, since its Choi operator is C(f)/d_E up to reordering of tensor factors.
- For a ∈ 𝔏_A define f_a(τ) = f(a ⊗ τ). Then f_a(T(H_E)) ⊆ 𝔏_B, because a ⊗ τ ∈ 𝔏_A ⊠ T(H_E). Also Ψ(f)(a) = C(f_a)/d_E ∈ 𝔏_{[E,𝔹]}. So Ψ(f) ∈ Hom(𝔸,[E,𝔹]).

*(c) ΦΨ = id.* Write Ψ(f)(X) = C(f_X)/d_E with f_X(τ) = f(X ⊗ τ), extended linearly. By (E0), ε(Ψ(f)(X) ⊗ Y) = f_X(Y) = f(X ⊗ Y).

*(d) ΨΦ = id.* Given g, write g(X) = C(h_X)/d_E for the unique linear h_X (Choi bijection). Then f = Φ(g) satisfies f(X ⊗ Y) = ε(g(X) ⊗ Y) = h_X(Y) by (E0). So Ψ(f)(X) = (1/d_E) Σ |i⟩⟨j| ⊗ h_X(|i⟩⟨j|) = C(h_X)/d_E = g(X).

*(e) Naturality in 𝔸.* For h ∈ Hom(𝔸′,𝔸), Φ(g∘h) = ε∘((g∘h) ⊗ id) = ε∘(g ⊗ id)∘(h ⊗ id) = Φ(g)∘(h ⊗ id_E).

*(f) Functoriality of [E,−].* For k ∈ Hom(𝔹,𝔹′) put [E,k] = id_{E*} ⊗ k, a CP map.
- Take C(f)/d_E ∈ 𝔏_{[E,𝔹]}. Then [E,k](C(f)/d_E) = C(k∘f)/d_E.
- Moreover k∘f ∈ HP and (k∘f)(T(H_E)) ⊆ k(𝔏_B) ⊆ 𝔏_{B′}, so the image lies in 𝔏_{[E,𝔹′]}.
- Functoriality holds because (id ⊗ k′)(id ⊗ k) = id ⊗ (k′∘k).

*(g) Naturality in 𝔹.* We must show Φ([E,k]∘g) = k∘Φ(g). Expanding, the left side is ε_{𝔹′}∘([E,k] ⊗ id_E)∘(g ⊗ id_E). It therefore suffices to prove counit naturality: ε_{𝔹′}∘([E,k] ⊗ id_E) = k∘ε_𝔹.
- Take any X ∈ B(H_{E*} ⊗ H_B) and Y ∈ B(H_E). Write X = C(h)/d_E with h linear. This is possible for every X by the Choi bijection, not only for admissible ones.
- Then ε_{𝔹′}(([E,k] ⊗ id)(X ⊗ Y)) = ε_{𝔹′}(C(k∘h)/d_E ⊗ Y) = (k∘h)(Y) by (E0) and Section 0.
- Also k(ε_𝔹(X ⊗ Y)) = k(h(Y)).
- The two agree. By linearity they agree on all of B(H_{E*} ⊗ H_B ⊗ H_E). ∎

**Corollary 1.** For first-order B, 𝒮_{[E,𝔅]} = {C(f)/d_E : f ∈ Chan(E,B)}, an affine copy of Chan(E,B).

*Proof.* f(T(H_E)) ⊆ T(H_B) iff f is trace-preserving and HP. Then C(f) ≥ 0 iff f is CP. ∎

## 4. Why this is the paper's obstruction

**Lemma K (Kraus rank).** For d_E, d_B ≥ 2, Chan(E,B) is not affinely isomorphic to State(ℂ^R) for any R.

*Proof.*
1. *State spaces.* State(ℂ^R) has dimension R²−1, and its extreme set (pure states) has dimension 2(R−1). An affine isomorphism is a semialgebraic homeomorphism that carries extreme points to extreme points. So both dimensions would have to match.
2. *Extreme channels.* By Choi, a channel with minimal Kraus family {K_i}_{i≤r} is extreme iff {K_i†K_j} are linearly independent, so r ≤ d_E.
3. *Strata.* Let N = d_E d_B and M_r = {J ∈ Herm⁺, rank r, Tr_B J = 1_E}. Rank-r PSD matrices form a manifold of dimension 2Nr − r².
4. *Submersion.* Tr_B is a submersion on M_r:
   - At J = KK†, tangent vectors are δK K† + K δK†.
   - A Hermitian H orthogonal to the image of d(Tr_B) must satisfy (H ⊗ 1)K = 0.
   - Since (H ⊗ 1)|K_i⟩⟩ = |K_iH^T⟩⟩, this gives K_iH^T = 0 for all i.
   - Because ΣK_i†K_i = 1 the Kraus operators have no common kernel, so H = 0.
   - Hence dim M_r = 2Nr − r² − d_E².
5. *Existence at r = d_E.* Take K_i = |v_i⟩⟨e_i| with unit vectors v_i ∈ ℂ^{d_B} that are pairwise non-orthogonal (possible since d_B ≥ 2). Then ΣK_i†K_i = 1 and K_i†K_j = ⟨v_i|v_j⟩ |e_i⟩⟨e_j| are independent.
6. *Extreme dimension.* Extremality is open in M_r. The dimension 2Nr − r² − d_E² increases in r for r < N, and r ≤ d_E < N. So dim Ext Chan(E,B) = 2d_E²(d_B − 1).
7. *Algebra.* An isomorphism needs 2d_E²(d_B − 1) = 2(R − 1) and R² − 1 = d_E²(d_B² − 1) (Prop. 3.1). Substituting R = d_E²(d_B − 1) + 1 into the second gives d_E²(d_B − 1) + 2 = d_B + 1, so d_E = 1. ∎

**Theorem 2.** Let d_E, d_B ≥ 2.
- (a) If a first-order R, with ε′ ∈ Chan(R⊗E,B), represents Chan(−⊗E,B), then State(R) ≅ Chan(E,B) affinely.
- (b) Hence [E,𝔅] is isomorphic to no first-order object, not even through an affine bijection of admissible-state sets.
- (c) In particular −⊗E has no right adjoint in Chan, taking B = E.

*Proof.* (a) At A = ℂ, g ↦ ε′∘(g ⊗ id) is an affine bijection Chan(ℂ,R) = State(R) → Chan(E,B), and by Corollary 1 the target is 𝒮_{[E,𝔅]}. (b) and (c) follow from Lemma K. ∎

**Proposition 3 (the intercept is a codimension).** dim 𝒮_{[E,𝔅]} = d_E²(d_B² − 1) = dim State(E*⊗B) − (d_E² − 1).

*Proof.* The left side is Prop. 3.1 at n = 1 with the source object E. The state space has dimension d_E²d_B² − 1. ∎

**Proposition 4 (graded instruments).** Let 𝔅_n = (H_B ⊗ ℂⁿ, 𝔏^bd) with 𝔏^bd = {Σ_i b_i ⊗ |i⟩⟨i| : b_i ∈ Herm, Σ tr b_i = 1}. Then:
- (i) Hom(𝔄, 𝔅_n) = Instr_n(A,B).
- (ii) Instr_n(A⊗E,B) ≅ Hom(𝔄, [E,𝔅_n]).
- (iii) dim 𝒮_{[E,𝔅_n]} = n·d_E²d_B² − d_E², which is dim 𝒮(𝔅_n(E*⊗B)) minus (d_E² − 1), independent of n.

*Proof.* (i) f(T(H_A)) ⊆ 𝔏^bd forces f(X) to be block-diagonal for all X, by spanning and complexification. Then f(X) = Σ_i E_i(X) ⊗ |i⟩⟨i|, with E_i = (1 ⊗ ⟨i|) f (·) (1 ⊗ |i⟩) CP. The trace condition gives ΣE_i trace-preserving. The converse is clear. (ii) follows from (i) and Theorem 1, since 𝔄⊗𝔼 = ι(A⊗E) by Prop. 2. (iii) By Corollary 1 applied to block-diagonal types and Prop. 3.1, dim Instr_n(E,B) = d_E²(n·d_B² − 1). The block-diagonal state space on E*⊗B⊗ℂⁿ has dimension n·d_E²d_B² − 1. ∎
